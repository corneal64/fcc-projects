# A Pomodoro Clock

A modern Pomodoro clock built with vanilla JavaScript, HTML and CSS.
This is a solution to Free Code Camp's Advanced Front End Development Projects - Build A Pomodoro Clock.

### Features

- Timestamp-based countdown timer (drift-free, accurate)
- Automatic transition between work and break sessions
- Circular progress ring showing remaining time
- Adjustable work and break lengths (1–60 minutes)
- Pause / resume / reset controls
- Session mode tabs (Work / Break)
- Completed cycle counter
- Audio chime on session completion (Web Audio API, no external files)
