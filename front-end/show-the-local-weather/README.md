# Show The Local Weather

A modern, responsive weather widget that shows the current weather and a 7-day forecast for your location.

This is a solution to Free Code Camp's 'Show the Local Weather' project.

## Features

- 🌍 Automatically detects your location via browser geolocation
- 🌡️ Current temperature, feels-like temperature, and weather conditions
- 💧 Humidity, wind speed, min/max temperature stats
- 🌅 Sunrise and sunset times
- 📅 7-day forecast with daily temperature ranges
- 🎨 Glassmorphism design with animated gradient background
- 📱 Fully responsive on all screen sizes

## Tech Stack

- **Open-Meteo API** - weather data (free, no API key required)
- **Photon (Komoot) API** - reverse geocoding for location names (free, no API key required)
- jQuery
- Font Awesome icons
- Poppins font (Google Fonts)
