# Simon Game

A modern, professional implementation of the classic Simon memory game, built with vanilla HTML, CSS, and JavaScript.

## Features

- **Modern UI** - Clean, dark-themed design with a circular center console and glowing pad animations
- **Two game modes** - Normal mode (replays the sequence on error) and Strict mode (restarts from level 1 on error)
- **Sound effects** - Classic Simon tones with a mute toggle
- **Keyboard accessibility** - Pads can be activated with Enter/Space keys
- **Responsive layout** - Works on desktop and mobile devices
- **No external dependencies** - Pure vanilla JavaScript, no jQuery or libraries

## How to Play

1. Click **Start** to begin
2. Watch the sequence of colored pads light up
3. Repeat the sequence by clicking the pads in the same order
4. Each level adds one more step to the sequence
5. Win by completing 20 levels

## Game Modes

- **Normal Mode** - If you make a mistake, the sequence replays so you can try again
- **Strict Mode** - If you make a mistake, the game restarts from level 1

## Controls

| Button               | Action                                   |
| -------------------- | ---------------------------------------- |
| Start / Restart      | Begin a new game or stop the current one |
| Normal / Strict Mode | Toggle between game modes                |
| Sound icon           | Toggle sound on/off                      |
